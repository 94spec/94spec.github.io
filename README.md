## Как устроен сайт

Одна статическая страница без сборщика, фреймворков и внешних запросов:

- `index.html` — вся разметка, стили и метаданные; контент лежит в HTML,
  поэтому страница читается поисковиками и превью-ботами без выполнения JS;
- `cv/` — резюме одной страницей плюс готовые PDF на русском и английском;
  PDF рендерятся из этой же страницы (`?lang=ru|en`) headless-браузером,
  поэтому текст резюме и текст на сайте не могут разойтись;
- `fonts/` — самостоятельно захостенные `woff2` (Archivo, JetBrains Mono),
  подключены через `unicode-range`, поэтому кириллица и латиница грузятся раздельно;
- JavaScript отвечает только за переключение RU/EN: без него страница
  полностью работоспособна и остаётся на русском;
- `scripts/check_page.py` — проверки, которые гоняет CI.

## Проверки

```bash
python scripts/check_page.py index.html
```

Скрипт валит сборку, если:

- разметка не сбалансирована или у `<img>` нет `alt`;
- в `<head>` пропали `description`, `canonical`, `og:*`, `twitter:card` или JSON-LD;
- якорь в меню ведёт на несуществующий раздел;
- пропал шрифт, иконка или другой локальный файл;
- в страницу попали `{{ … }}`, `TODO:`, `Math.random` или внутренние имена систем;
- страница выросла больше 250 КБ.

Дополнительно workflow `validate` проверяет, что контент виден без JavaScript,
что публичные ссылки и контакты на месте и что ключевые метрики на странице
по-прежнему сопровождаются знаменателями.

## Принцип подачи

У каждой цифры на сайте указан знаменатель и правило сравнения. Числа,
которые нельзя раскрывать, не публикуются вовсе — вместо них описан метод.
Анимации носят иллюстративный характер и подписаны как синтетические:
на странице нет ни одного значения, которое выдавалось бы за живую телеметрию.
